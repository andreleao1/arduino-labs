# Arduino Labs

This repository contains the source codes and projects developed during our Arduino classes.  
Each project is organized in its own dedicated folder and includes the following materials:

- **Arduino code (.ino file):** The main source code of the project.  
- **Project description:** A short explanation of the code and the project idea.  
- **Circuit diagram:** An image of the schematic used in the project.  
- **Breadboard setup:** A photo of the circuit assembled on the breadboard.  
- **Demo video (if available):** A short video showing the project in action.

## Goal

The main goal of this repository is to make the class content more accessible by providing:  
1. Well-structured code examples.  
2. Visual representations of the circuits.  
3. Explanations that reinforce the concepts learned in class.  

---

## How to Use

1. Navigate to the project folder you want to explore.  
2. Open the `.ino` file with the **Arduino IDE** or **Arduino CLI**.  
3. Build the circuit using the provided diagram and breadboard photo.  
4. Upload the code to your Arduino board and watch it in action!  

---

## Requirements

- Arduino IDE (or Arduino CLI)  
- Arduino board (e.g., Uno, Mega, Nano)  
- Basic electronic components (resistors, LEDs, sensors, etc.)
