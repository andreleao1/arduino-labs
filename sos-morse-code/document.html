SOS Morse Code with Arduino

Learn how to create an SOS signal in Morse code using Arduino, a push button, and an LED

Project Overview

This project demonstrates how to emit the word SOS in Morse code using an Arduino, a push button, and an LED. When the button is pressed, the Arduino turns the LED on and off in the correct timing pattern for Morse code.

The goal is to help students practice digital I/O handling, timing with delays, and basic electronics concepts using Arduino.

Morse Code Timing

Morse code is a method of transmitting text information as a series of on-off tones, lights, or clicks.

For this project, we use the following timing:

  • Dot: LED ON for 200 ms
  • Dash: LED ON for 600 ms (3 times longer than a dot)
  • Space between parts of the same letter: OFF for 200 ms
  • Space between letters: OFF for 600 ms

Hardware Setup

Components List

  • Arduino Uno board
  • 1x LED (any color)
  • 1x Push button
  • 1x 330Ω resistor (for LED)
  • 1x 10kΩ resistor (pull-down for button)
  • Breadboard and jumper wires

Pin Connections

  • LED connected to digital pin 7
  • Button connected to digital pin 6
  • 10kΩ resistor used as pull-down for the button
  • 330Ω resistor in series with the LED

Resistor Calculations

Why a 330Ω Resistor for the LED?

Arduino pins can source or sink up to 40mA, but the safe recommended operating current for an LED is 10–20mA.

The resistor value is calculated using Ohm's Law:

R = (Vsource - VLED) / I

Where:

  • Arduino output voltage: 5V
  • Typical LED forward voltage: 2V (red LED, approximate)
  • Desired current: 15mA = 0.015A
R = (5V - 2V) / 0.015A ≈ 200Ω

A 220Ω resistor would work, but to further reduce current and extend LED lifespan, a 330Ω resistor is used:

I = (5V - 2V) / 330Ω ≈ 9.1mA

Why a 10kΩ Resistor for the Button?

When no resistor is used, the input pin can "float" and randomly switch between HIGH and LOW due to electrical noise.

A 10kΩ resistor is a common and safe value for pull-down resistors:

  • Small enough to keep the input stable at LOW when the button is not pressed
  • Large enough to avoid wasting unnecessary current when the button is pressed
